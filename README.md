<h1 align="center">🏭 Production Pulse AI</h1>

<h3 align="center">
AI-Powered Production Risk Monitoring & Factory Automation System
</h3>

<p align="center">
An AI-driven manufacturing monitoring workflow built with <strong>n8n</strong>, 
<strong>OpenAI</strong>, and <strong>Google Sheets</strong>.
</p>

<hr>

<h2>🚀 Overview</h2>

<p>
Production Pulse AI is a smart factory automation workflow that monitors production data,
detects operational risks, and automatically alerts teams before delays become critical.
</p>

<p>
The system analyzes:
</p>

<ul>
  <li>Production completion rates</li>
  <li>Machine downtime</li>
  <li>Scrap rates</li>
  <li>Missing production quantities</li>
  <li>Operational bottlenecks</li>
</ul>

<p>
Using AI Agents, the workflow generates risk analysis, identifies root causes,
and recommends corrective actions automatically.
</p>

<hr>

<h2>🧠 Key Features</h2>

<ul>
  <li>AI-based production risk analysis</li>
